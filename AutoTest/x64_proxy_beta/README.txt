WarVK x64 渲染代理 内测版（2026-11-18）
========================================

这是什么
--------
魔兽争霸 III 是 32 位程序，能用的地址空间只有 2 GiB 左右，大地图容易因此崩溃。
这个版本把 Vulkan 渲染放到一个独立的 64 位进程里，给游戏进程腾出地址空间。

这是内测版，可能出现画面问题、闪退或进不了游戏。请不要用它打重要的对局。


需要什么
--------
  - 64 位 Windows 10 或 Windows 11
  - 魔兽争霸 III 1.27a（Game.dll 版本 1.27.0.52240）
  - 支持 Vulkan 1.3 的显卡，并安装较新的显卡驱动


怎么用
------
  1. 如果游戏目录里已经有 d3d9.dll（其他图形插件或旧版 WarVK），先把它复制到别处备份。
  2. 把压缩包里的全部内容解压到 war3.exe 所在的目录，提示覆盖时选择覆盖。
     解压后，war3.exe 旁边应该直接有 d3d9.dll 和 WarVK 文件夹。
  3. 和平时一样启动魔兽争霸。不需要运行其他程序。


怎么确认已经生效
----------------
游戏运行时，任务管理器里会多一个 warvk-d3d9-host.exe，
WarVK\logs 里也会多一个以当前时间命名的文件夹。

如果 64 位渲染进程启动失败，或者游戏不是 1.27a，游戏会自动改用原来的 WarVK 方式继续运行。
这时任务管理器里没有 warvk-d3d9-host.exe，日志文件夹里会有 fallback.txt，写明原因。


怎么卸载
--------
  1. 退出游戏。
  2. 删除游戏目录里的 d3d9.dll 和“WarVK内测版说明.txt”。
  3. 删除 WarVK 文件夹里的 x64、logs、cache 三个文件夹。
  4. 如果之前备份过 d3d9.dll，把它放回游戏目录。

只想暂时不用 64 位渲染：删除或改名 WarVK\x64 文件夹，游戏会使用原来的 WarVK 方式。


已知限制
--------
  - 请保持抗锯齿（MSAA）关闭，这个模式还不支持。
  - 游戏运行中如果 64 位渲染进程出错，游戏会退出，不能中途切换回原来的方式。
  - Alt-Tab 切换、拖动改变窗口大小、最小化后恢复、运行中修改系统缩放，还没有经过自动化测试，
    如果遇到问题请告诉我们。
  - 全屏目前只支持主显示器的当前分辨率，还没有充分测试。建议先用窗口模式。
  - 多了一个 64 位进程，CPU 占用的分布和原来不同，帧率可能比平时高也可能低。
  - 文件没有数字签名，杀毒软件可能拦截或误报。请只使用测试负责人发给你的压缩包，
    可以用 WarVK\x64\SHA256SUMS.txt 核对文件。

遇到问题时
----------
请把 WarVK\logs 里对应时间的那个文件夹整个打包，发给测试负责人。游戏崩溃时，
也请带上游戏目录 Errors 文件夹里最新的文件。并说明：
  - 用的是哪张地图，出问题前在做什么
  - 显卡型号、驱动版本、Windows 版本
  - 是窗口模式还是全屏

日志里可能带有本机路径和用户名，发送前可以先看一下。
日志只保留最近 20 次启动的记录。


开源许可
--------
本包包含的第三方组件的许可证在 WarVK\x64\licenses 文件夹里。
