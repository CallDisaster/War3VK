# 注意：Native 文件夹开发规范

## [重要] 核心原则
`native/` 文件夹中的代码主要用于以下目的：
1. **逆向还原**：记录和演示魔兽争霸 III (1.27.x) 原生函数的逻辑还原。
2. **参考实现**：作为一套完整的、致力于 1:1 还原原版行为的参考代码，供调试和对比使用。

### ⚠️ 警告：请勿在此修改业务逻辑
**不要出于功能性需求或修复游戏 Bug 的目的修改此文件夹中的代码。** 

- 真正的业务逻辑、修复补丁和功能扩展应当实现在 `hook/` 文件夹或 `src/d3d9/d3d9_war3_hook.cpp` 等 Hook 层中。
- 此文件夹中的 `Native_` 函数在正常运行流程中**不应被直接调用**（除非在专门的测试模式下）。
- 修改此文件夹代码仅限于：
    - 补充更准确的逆向工程还原。
    - 修复参考代码本身的逻辑错误（例如与原版汇编不符的地方）。
    - 完善函数重命名和文档注释。

## 开发建议
如果你发现通过 Hook 接管的功能有 Bug，请检查对应的 Hook 包装函数及其在 Hook 层中的逻辑分发，而不是修改这里的“死参考”。
