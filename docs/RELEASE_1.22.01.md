# WarVK 1.22.01 内存维护修复版

范围：动态快照/Arena扩页预算、退役空洞复用、Arena空闲尾页缩减、Image异常清理、
D3D9小尾段与溢出处理、截图读回槽按需分配。完整说明见根CHANGELOG与中英README。
没有新增视觉特性、64位产品或caster/剔除宽松准入。

## 接受依据与变更边界

用户于2026-09-20反馈“测试了一轮没有什么问题”，授权主线程决定继续优化或推送修复版；
主线程选择冻结并发布，不继续混入新优化。玩家现场DLL经只读核验为36,065,732 bytes /
`028565BCB33B6EB646E4915115B60CDA3C14C287A4225DAA50F8F6513F9E9BA3`，
与交付候选完全相同。此反馈未包含新性能报告或测试矩阵，不扩写为全量GPU/长期验收。

候选离线CPU99/99、静态275/275；正式版只改变产品/JAPI显示版本、相应版本探针和文档/打包。
最终构建再次运行离线门、正式配置核验与精确DLL no-work；结果与最终身份记录于发布回执。
Shader ABI1.2.0及JASS wire v1不变。未重新部署/启动玩家游戏。

## 保留边界

真实活跃集合超预算、元数据耗尽/碎片、驱动缓存释放延迟仍可能存在。动态额度不保证永不OOM。
同进程跨地图、所有历史短时阴影异常、慢磁盘退出、诊断跨attempt恢复归因仍未完全闭合。
继续建议每张地图重新启动进程；保留旧DLL以便退出游戏后回退。
