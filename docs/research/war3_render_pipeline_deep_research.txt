第一部分：项目背景与核心问题

## 我们的项目
我们在魔兽争霸3 1.27a 中注入了一个 DXVK (Direct3D9 → Vulkan) 翻译层，并在引擎内部安插了
MinHook 来劫持渲染管线，目的是为所有单位添加高质量的动态阴影。

## 当前阻塞
1. 阴影的 Pose（动画姿态）刷新率极低，跟不上主场景中模型的动画。
2. 飞行单位、建筑、可破坏物、装饰物完全没有阴影。
3. 大量阴影渲染时出现顶点撕裂（顶点拉伸/错乱）。

## 核心矛盾
我们的阴影贴图在 BeforeUi（主场景渲染前）就烘焙好了，但引擎在主场景渲染过程中才计算
骨骼动画和写入调色板。因此阴影贴图永远落后主场景至少一帧（甚至更多帧）。

## 你的任务
1. 校验我们逆向的所有结构体字段是否正确。
2. 校验我们逆向的所有函数语义是否正确。
3. 补齐我们不知道的字段语义。
4. 提出解决上述阻塞问题的技术方案。
5. 重点关注 CPU 蒙皮（skinning）的完整流程：从动画计算 → 骨骼矩阵 → 调色板混合 → 顶点变换。

// 从全局矩阵池读取原始矩阵，为每个矩阵组做混合，输出到目标调色板缓冲区
// 参数: a1=CGeosetData* (geosetData), a2=全局矩阵池基址(dword_6FBEE648), a3=输出缓冲区
__m128i *__fastcall CGeosetData_BuildGroupBlendedPalette(_DWORD *a1, const __m128i *a2, __m128i *a3)
{
  v4 = a1[60];              // a1 + 0xF0 = MatrixGroupCount
  if (v4) {
    v5 = (_DWORD *)a1[64];  // a1 + 0x100 = MatrixIndices (扁平化索引数组)
    v6 = (unsigned int *)a1[61]; // a1 + 0xF4 = MatrixGroupSizes (每组几个矩阵)
    do {
      CMatrixGroup_BlendOutputMatrix((int)a2, v5, *v6, a3);
      v7 = *v6++;            // 当前组的矩阵数量
      v5 += v7;              // 索引指针前进 v7 个 uint32_t
      a3 += 3;               // 输出前进 3 个 __m128i = 48 字节
      --v4;
    } while (v4);
  } else {
    // 只有单个矩阵：直接拷贝，不做混合
    *a3 = _mm_loadu_si128(a2);
    a3[1] = _mm_loadu_si128(a2 + 1);
    a3[2] = _mm_loadu_si128(a2 + 2);
  }
  return a3;
}

// 全局调色板槽位的 bump 分配器。返回的 slotIndex 写入 RenderablePart+0x08。
// 参数 this = 分配大小（来自 meshData+240，通常是矩阵组数量）
int __thiscall RenderQueue_AllocPaletteSlot(void *this)
{
  // 帧检测
  v3 = GetGameFrameCounter(1);
  if (v3 == dword_6FBDA4CC) {  // 同一帧
    v4 = dword_6FBDA4C8;       // 继续从当前偏移累积
  } else {
    dword_6FBDA4CC = v3;       // 新帧 → 记录帧标识
    v4 = 0;                    // 重置每帧偏移
  }
  dword_6FBDA4C8 = (int)this + v4;  // 累积偏移 += this(分配大小)
  
  // dword_6FBDA4C8 溢出检查 (max 0x3A98=15000)
  if (this + v4 >= 0x3A98) {
    dword_6FBDA4C8 = 0;
  }
  
  // dword_6FBC6BE4: 全局线性 bump 分配器
  v5 = dword_6FBC6BE4;        // 保存旧光标作为返回值
  if (this + dword_6FBC6BE4 > 0x7530)  // 溢出检查 (max 0x7530=30000)
    v5 = 0;
  dword_6FBC6BE4 = (int)this + v5;  // 新光标 = 旧 + 大小
  return v5;                   // 返回旧光标 = slotIndex
}

// 遍历 CModel 的所有 Geoset(RenderablePart)，为每个分配调色板槽位并填充混合调色板
// 参数: this = CModel*
_DWORD *__thiscall CModel_AllocAndFillGroupPalette(_DWORD *this)
{
  v2 = *(this + 3);        // CModel + 0x0C = geosetCount
  for (i = (int *)*(this + 4); v2; ++i) {  // CModel + 0x10 = geosetArray
    v4 = *i;               // 当前 geoset 指针
    --v2;
    if (!*(_DWORD *)(*i + 16)) {  // geoset + 0x10 = SkipFlag (0 才执行)
      v5 = *(_DWORD *)(v4 + 12);  // geoset + 0x0C = meshData 指针
      if (*(_BYTE *)(result[8] + 16 * *(_DWORD *)(v5 + 284) + 3)) {
        // meshData + 0x11C → 某个标志字段中的 bit
        v6 = RenderQueue_AllocPaletteSlot(*(_DWORD *)(v5 + 240));
        //                                        meshData + 0xF0 = 分配大小
        *(_DWORD *)(v4 + 8) = v6;  // geoset/RenderablePart + 0x08 = slotIndex
        v7 = RenderQueue_GetPaletteSlotAddress(v6);
        //     → 返回 dword_6FBC6BD0 + 48*slotIndex
        CGeosetData_BuildGroupBlendedPalette(v7);
        //     → 传入输出缓冲区地址
      }
    }
  }
  return result;
}

## 7.1 数据流

[动画数据] → CModelAnimController::AdvanceTime
  → 计算每根骨骼的局部变换矩阵
  → 层级传播 (parent→child 矩阵级联)
  → 写入 全局矩阵池 dword_6FBEE648
  → CModel_AllocAndFillGroupPalette
    → 为每个 RenderablePart(Geoset):
      → RenderQueue_AllocPaletteSlot → 分配 slotIndex → 写入 +0x08
      → CGeosetData_BuildGroupBlendedPalette:
        → 读取 CGeosetData+0xF0 → groupCount
        → 读取 CGeosetData+0xF4 → matrixGroupSizes[i] (每组几个矩阵)
        → 读取 CGeosetData+0x100 → matrixIndices (扁平化，指向矩阵池中的位置)
        → CMatrixGroup_BlendOutputMatrix(矩阵池, matrixIndices, matrixGroupSizes[i], 输出):
          → 单骨骼(1): 直接拷贝矩阵池数据
          → 双骨骼(2): (矩阵A+矩阵B)×0.5 (等权平均)
          → N骨骼(N): 累加后÷N (等权平均)
        → 输出到 dword_6FBC6BD0 + 48*slotIndex + group*48
  → 渲染时：
    → GxDevice 读取 CGeosetData+0x4C → vertexGroupIndices[i]
    → vertexGroupIndices[i] → 索引到 dword_6FBC6BD0 + 48*slotIndex + group*48
    → 取出混合后的矩阵 → 变换顶点位置 → CPU 蒙皮完成
    → DrawPrimitiveUP 提交变形后的顶点

## 7.2 关键数据格式

调色板矩阵格式 (3x4, 48 字节):
  float pose3x4[12];  // 前三行是 3x4 仿射矩阵，第四行隐含为 (0,0,0,1)
  
全局缓冲区布局 (dword_6FBC6BD0):
  dword_6FBC6BD0 → 堆上分配的缓冲区指针
  每个槽位: 48 字节 × slotIndex 偏移  
  每个槽位内的布局: [Group0的3x4矩阵(48B)][Group1的3x4矩阵(48B)]...[GroupN的3x4矩阵(48B)]

顶点→矩阵映射:
  CGeosetData+0x4C → vertexGroupIndices[vertexIndex] = groupSlot
  groupSlot 直接作为调色板中的索引 → palette[groupSlot] 就是该顶点用的矩阵
