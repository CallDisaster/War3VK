## 2. 64位基础已走通的链路

```text
独立32位CPU测试进程
  producer：只做有界copy；队满立即记丢样，不等待宿主
    -> 私有4槽队列（约256 KiB）
    -> 独占I/O的worker
    -> 本地管道：版本/位数/实际进程身份/nonce/代际/序号
    -> 4 x 64 KiB共享容器：租约、写入完成、取消隔离
独立64位宿主
    -> 有限等待 + 私有copy + SHA校验 + 样本语义校验
    -> CPU消费ACK
32位owner等待精确子进程退出后释放本连接容器
```

这是实际lab链路，不是游戏内已经存在的接线。ACK仅证明指定CPU消费，不是GPU完成或GPU资源释放许可。
