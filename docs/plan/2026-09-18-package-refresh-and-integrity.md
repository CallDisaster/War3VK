## 4. 每个包的 MANIFEST 里都写明了什么

**C 与 D 的 MANIFEST 都含「范围声明」**：包内 DLL 是**打包时刻的整树构建**，
同时包含其它阶段的改动（C 包装配时 DLL 含 D 与 E；D 包装配时含 C 与 E）。
原因：各阶段在同一构建期内完成，**没有**为出包单独回退其它阶段再重建 ——
那会产出**从未被验证过**的二进制。

⇒ 两个包都明写「**不能**当作"纯 C / 纯 D 的二进制"」。

**B 的 MANIFEST** 明写：包内往返测试载体**同时承载 D 的 B1 屏障块**，
它落在这个二进制里**仅为链接原因**。
