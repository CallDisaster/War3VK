## 2. 对这两项的性质判定（**不是**回归）

| 证据 | 含义 |
| --- | --- |
| 两者未带参数时打印 `argc==3` | 它们**要求命令行参数**，不是独立可运行测试 |
| 在 `AutoTest/` 中 grep `war3_frame_recorder_defaults` **无任何命中** | 没有任何门禁脚本以记录在案的方式驱动它们 |
| 带参数 `0 1` 运行 `_1` 后输出 `mode=="explicit-on"` 仍非零 | 参数语义与我猜测不同；无法在无文档的情况下驱动 |
| 名称后缀 `_0` / `_1` | 应为**编译期宏的两个变体**（记录器默认值关闭/开启），各自断言自己的模式 |
| meson 套件 **85/85 全绿** | 若这两者属于 meson 套件，其参数会由 `test(...)` 提供；事实并非如此 |

⇒ 准确表述：**它们是参数化的模式探针，不属于 meson 测试套件，本轮未以正确参数驱动它们**。
**我没有证据表明它们通过，也没有证据表明它们回归。**不得把二者计入"通过"。
