# 一次误读的更正 + 下一步（不依赖实机的工作仍在）— 2026-09-18

## 1. 我更正一个自己刚犯的错

我用 Python 打印 `bool(OpenProcess(0x1000, False, 18948))` 得到 `False`，据此判断"进程已消失"并宣布环境干净。
**这是错的。** 同一时刻 PowerShell 显示 `ALIVE pid=18948`；随后的运行也被前置检查拦停：

```
ABORT: a game/editor process is already running; refusing to start a dirty run:
    War3.exe  18948 Console  1  505,448 K
```

**根因**：`OpenProcess` 返回**空句柄**既可能是"进程不存在"，也可能是"**拒绝访问**"——
而本会话对这类进程恰好**一贯是拒绝访问**。我把一个**歧义信号**读成了确定结论。

⇒ 教训（第四条，与前三条同源）：**不要把"某个调用失败"直接翻译成"世界处于我期望的状态"。**
此前三条：①只读部分输出；②把"机制看起来对"当成已验证；③把"符号存在"当成端到端可用。
本条是：④**把"无法观测"当成"观测到否定"**。

**正确的判据**（本轮实际用的）：`Get-Process -Id <pid>` 与 `tasklist /FI "PID eq <pid>"`；
两者一致才下结论，且不把 `OpenProcess` 的失败当作存活判据。
