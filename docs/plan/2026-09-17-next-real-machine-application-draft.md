## 7. 判定口径（不得越界）

1. **本轮首先回答「路径与对象关系」**；其余问题一律写成开放项。
2. **保留既有「不得冒充」清单**（不得当作通过证据）：
   - 拒绝计数增长（31,881→88,926→91,039 一类）；
   - `ServedAfterConfirm == 0`（只支持「该运行未观察到」，不得定性为结构性死代码）；
   - `ProducerSnapshotFallback` / 快照回退计数增长（是分母，不是同一对象被接住的证明）；
   - 细分拒绝之和 == 聚合 `RejectedStale`（只证明分母自洽）；
   - 「接线完成」/「字段已导出」；
   - 单个对象样本外推全体；
   - 受控终止下驱动 `exit 0`；
   - `ENDFRAME_BUILD` / `PUBLISH_REGISTRIES_BEFORE_SCENE` 类门打开后得出的结论外推为默认生产路径；
   - 用「合同 ON/OFF 差异」直接解释对象级证据差异。
3. **新增（上级本轮要求）**：
   - **「取到 palette」不得写成「阴影恢复」**（恢复必须有实际提交与绘制证据）；
   - **「未请求 drain 路径」不得升级为「全进程无竞争 / 数据未受影响」**。
4. 统计口径：0.5s 采样是「采样点最大值/占比」，**不是完整逐帧统计**；`shadowStats` 类字段为**当帧值**，
   其 Δ 不表示累计增量；进程累计原子才可用分段增量。
5. `CanonicalReadyCount=0` 只支持「该运行未观察到就绪」。
6. 任何一项缺同对象关联时，只能写「观察结果（部分）」或「未覆盖」。
