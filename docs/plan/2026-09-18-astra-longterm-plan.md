## 2. 为什么把「阶段 F」定为下一个大阶段

现在这条证据链能回答"某个对象发生了哪几步"，但**还不能**可靠地回答**能下什么结论**。
项目的最高纪律就是这件事：「一张表不代表一种事实，一条链结算不代表观察完整，观察完整不代表对象已证明」。
而这句话目前**只写在文档里**，**没有**机器可裁决的形式。

阶段 F 的四个子项（都可离线验收）：

```
F1  读方结论的判定表：每条链 ⇒ 结论 + 触发依据 + 反例清单（机器可裁决，不是散文）
F2  离线汇总装置：一批导出 ⇒ 对象级汇总（被拒绝 / 已恢复 / 仅观察 / 未闭合）+ 跨链矛盾检测
F3  证据充分性判据（可机检）：明确"在什么条件下才允许说 X"，把纪律变成门禁
F4  用**带已知答案的合成导出**验证 F2/F3 —— 这是可无人值守的验收方式
```

**为什么它值得做**：它会**结构性**地阻止本项目反复出现的失败模式 ——
把"观察到一步"当成"对象已证明"、把"一条链结算"当成"观察完整"。
