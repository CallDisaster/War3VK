## 2. 那 32 条假链是怎么来的

关键：**首见条目在发射之前，其 `sawFirstSight` 也是 `false`**。

```
修正② 之前：
  预算拒发 ⇒ NoteFirstSight 已建条目，但 !sawFirstSight
  ⇒ 该条目走 :269 的 false 分支（那是给**拒绝恢复链**准备的）
  ⇒ 终态 stage = Drawn  ⇒ 读方看到 [Drawn]，而它从未被观测
```

⇒ 这**不是**"回填规则写错了"，而是**"首见链的未发射条目被误分类成拒绝恢复链形状"**。

**修正② 通过"不建这种条目"堵掉了这个泄漏**（实机：假链签名 32 → 0）。
