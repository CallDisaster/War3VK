# WarVK 1.22.03 发布范围与证据

发布日期：2026-11-12。用户授权：“这个当成小版本更新将该功能发布吧，还有就是玩家反馈我们的光影相关
内容会干涉到单位头像框中的模型看起来过暗或者过亮，还有每次玩家打开菜单栏的时候游戏被暂停时我们的
渲染层的阴影、体积光之类的会叠到UI之上，这也是个bug。目前体积光的阴影分辨率有些过低以及还是有些
不够明显。请你解决这些问题后将该小版本发布。”

## 范围

收入（玩家 DLL 默认生效）：

- Ctrl+F1 面板设置自动保存到 `WarVK\settings.ini`（c5b5774，说明见 CHANGELOG）。
- 世界光照作用域：太阳/环境光/材质改写只在世界 `RenderScene` 内生效，头像等其他场景用游戏原值。
- BeforeUi 分界第 10 层（世界场景返回后的第一次绘制）与帧末兜底守卫。
- 换图信号：世界仍在渲染时的脚本入口重入不再算换图。这一项不在用户列出的问题里，是排查
  体积光时在对战图上发现的：1.22.02 同样存在，属于“阴影偶发闪烁”一类，一并修复。
- 体积光：专用阴影图 2048、近层比例 0.30、引导图取预算内最细一档；默认强度 1.5、对比 2.5、
  可读性压暗上限 0.36。体积光仍默认关闭。

不变：Shader API 1.2.0、JASS wire `warvk:v1`、109 个命令的集合、显卡/驱动下限、64 位渲染宿主等
开发选项（正式配置中全部为 false）。作者包除版本号说明外与 1.22.02 相同。

## 根因与证据

均在 AutoTest 专用沙盒 + 隔离桌面里先复现、后验证；对照组是已发布的 1.22.02 DLL
（`587D2942…72A5`）。

| 问题 | 根因 | 复现与修复后的数据 |
| --- | --- | --- |
| 头像过暗/过亮 | `SetLight(0)`/`SetMaterial`/`D3DRS_AMBIENT` 的改写不分场景。头像模型在世界 `RenderScene` 之外绘制，却被套上世界太阳。 | 同一机位头像平均亮度：1.22.02 正午/午夜/黎明 90.7/82.0/117.7；本版 126.3/126.8/125.5。最终 DLL 在对战图上四个时段 61.8～62.3（同时世界亮度 44.8～62.8）。 |
| 暂停时效果盖住界面 | 真实暂停（单机 F10）下世界阶段以 `a5 != 0` 分发，且没有 15/18/21 阶段。旧分界条件“主世界 21 阶段完成且到过 15”永不成立，BeforeUi 只能在 `Present` 帧末兜底执行，此时界面已画完。测试接口 `game.pause`（JASS `PauseGame`）不走这条路径，复现必须用真实按键并关闭测试工具默认的暂停屏蔽。 | 逐帧阶段序列：正常帧 `Scene{ s1 … s15 s18 s21 }`，暂停帧 `Scene{ o1 … o20 }` 后接约 269 次界面绘制。修复后两种帧都在第 10 层提交，日志中无帧末兜底记录；最终 DLL 暂停帧与恢复后的小地图区块逐像素相同。 |
| 对战局阴影每秒丢帧 | `Game.dll+0x890960`（地址簿里的 mainRunner）不只运行地图 `main`，每次恢复 JASS 线程都会进入。`War3MapTransitionGate` 的兜底把“再次进入”当成换图，请求重置阴影会话。 | (2)EchoIsles（含电脑玩家）上，1.22.02 发布 DLL 的整帧拒绝计数 1200 帧内 +7188、56400 帧内会话隔离 392 次；换图逻辑相同的修复前开发构建 1200 帧内 24 次重置请求、9 次纪元切换，每次整帧拒绝全部 387 次绘制，截图可见该帧没有阴影。本版同图 15600 帧：纪元 1、请求 0、拒绝 0。无 AI 脚本的自定义地图上原本就不出现。 |
| 体积光阴影粗、不明显 | 近层覆盖半径 4200 只有 1536 纹素；引导图只有 1/2 与“等于效果分辨率”两档；俯视角下物理散射的受光/遮挡对比只有约 12 级。 | 近层 5.47→2.93 世界单位/纹素，远层 13.0→9.8；1440p 引导图 1/8→1/3、4K 1/8→1/4（预算 1 亿格不变）。同机位受光/遮挡对比（p95−p5）12.0→14.7 级，被完全遮挡的光柱对底色压暗 24%→35.8%。 |

  1.22.03、非预发布；精确目标再次构建为 no-work。配置审计 `{"ok":true,"errors":[]}`。

## 未验证与已知边界

- **这一个 DLL 没有玩家实机验收。** 玩家现场仍运行 2026-09-25 的候选（`1FFE0BD1…35CF`），本次
  没有覆盖或部署它。
- 只在一块 NVIDIA RTX 4060 Ti 上做了隔离自动化测试。
- 暂停修复只验证了单机 F10 暂停（两张地图）。联机暂停、过场动画、隐藏界面等帧形态没有专项测试；
  隐藏界面时世界之后没有绘制，仍走原来的帧末路径。
- 光照作用域之外的 3D 场景（主菜单背景、加载画面模型、过场头像）现在使用游戏自己的灯光，这是
  预期变化，但没有逐个截图对比。`RenderScene` 钩子未触发的环境保持旧行为（全程改写）。
- “世界仍在渲染”以“世界场景在本帧或上一帧完成”为准。联机局打开全屏日志/任务界面时世界不渲染，
  此时线程恢复仍会触发一次重置，回到游戏后阴影重建一帧；与旧版行为相同，未改善。
- 体积光新默认值是按一张对战图在早晨与黄昏两个时段的截图调的，不是美术验收；俯视角下它仍以整体
  雾化为主，光柱对比提升有限（约 12→15 级）。2560×1440 高档的效果分辨率仍为 1/8，这是防 TDR 的
  工作量上限，没有放宽。体积光开启时显存多占约 14 MiB（两层 D32：1536²→2048²）。
- 正常退出、菜单换图、D3D9 Reset、长时高压仍未完成验收；继续建议每张地图重开游戏。
- Shader API 1.2.0、JASS wire `warvk:v1` 不变；没有新的 FPS 提升承诺。
