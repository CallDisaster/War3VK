# WarVK v1.22.00

面向 Warcraft III 1.27a / 32位的正式更新。重点是吞吐、阴影资源恢复、蒙皮输入保护与诊断可用性。

## 主要更新

- 跳过已核验的普通帧无消费者后缓冲读回，让CPU/GPU恢复并行；性能录制开关不再决定是否启用。
- 原生截图按需GPU复制、精确完成后后台保存TGA，不再为普通帧截图同步付出等待。
- 快照三流按保留寿命分页，解除无用引用、修正失败续期，缓解大地图走动后的粘滞失影；默认384MiB不增加。
- Issue #8短时拉长阴影：修正旧palette槽位复用、组数覆盖与来源/坐标空间交接；异常输入已复算，
  修复纳入本版，随机视觉问题仍继续收集回归，不宣称全部地图已根治。
- 太阳关闭语义与typed JASS签名修正，保留显式点光、局部雾、Froxel和Guide。
- Ctrl+F1 Render Stats显示真实资源统计，修正缓存命中帧假零；Arena区分保留容量和提交代使用量。
- 所有者线程/工作代际、进度发布和构造失败清理加固；正式版默认关闭重型取证。

## 同步优化原理

旧LockRect等待的是GPU数据就绪，不是固定5ms sleep；无像素消费者的普通同步仍触发了这次等待。
跳过它提高流水线吞吐，不等同于着色器更快或输入延迟已降低。
历史隔离同DLL ABBA测得Present间隔13.155→7.840ms（-40.40%），倒数吞吐+67.78%；
**这不是正式v1.21→v1.22的通用FPS同比**，实际体验随地图、镜头和效果变化。

## 安装与兼容

Windows 10/11、Vulkan 1.3及最新官方驱动。完全退出游戏，备份旧DLL后把玩家包d3d9.dll放到war3.exe旁。
普通启动即可，不用旧诊断脚本；Ctrl+F1设置。地图作者另取author-kit；无游戏资产或DLL Loader。
产品/JAPI1.22.00，Shader API1.2.0、JASS wire warvk:v1不变。

## 已知边界

- 每张地图使用新进程；同进程跨地图仍不保证。
- 真正超大工作集仍会遇到有限预算；Arena高水位保留页尚不自动缩容。容量满不等于本帧分配失败。
- 1440p/4K极端Froxel可安全回退Legacy；部分细轮廓/点阴影和未覆盖API仍需逐场景检查。
- 未完成Water、原版模型自动灯、64位渲染产品及未验收剔除实验不包含在内。
- 用户试玩RC后批准发布；最终统计修正另做离线回归，不伪称已做最终新DLL全量GPU/长时验收。
