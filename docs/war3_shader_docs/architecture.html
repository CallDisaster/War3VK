项目概览

War3MapReforge 基于 DXVK 的 D3D9→Vulkan 转译层，在不改动游戏资源的前提下，通过分域 Hook + 桥接链路插入阴影、描边、材质覆盖与后处理能力。

当前架构（2026-02-22） 已从“单入口大文件”升级为“薄中枢 + 分域模块”：d3d9_war3_hook.cpp 仅负责生命周期编排，渲染/JASS/生命周期/UI/Shadow 逻辑分别驻留在 src/d3d9/war3/hooks/。

DXVK Core
D3D9 API 适配、资源生命周期、命令录制与 Vulkan 提交。
War3 Runtime Orchestrator
d3d9_war3_hook.cpp 负责模块探测、版本门禁、地址解析与分域装配。
Domain Hooks
war3_hook_render/lifecycle/jass/ui/shadow 按职责独立演进。
Bridge + Shader
render/* + shader/* 完成对象桥接、材质覆盖、统计与诊断。

目录说明

src/d3d9/d3d9_war3_hook.cpp
War3 入口中枢，负责模块校验、版本门禁、生命周期编排与装配。
src/d3d9/war3/hooks/
分域 Hook 模块，按 Render/JASS/Lifecycle/UI/Shadow 拆分，并将 Shadow 过滤策略独立为 policy。
src/d3d9/war3/render/ + handle/
桥接链路与对象追踪核心，负责从渲染数据回查逻辑对象身份。
src/d3d9/war3/shader/
材质系统与全局 Uniform 管理，提供 ShaderPack 接口。
src/d3d9/war3/platform/war3_runtime_bootstrap.*
运行时核心初始化/重置编排，降低入口文件对细节模块的耦合。
src/d3d9/d3d9_war3_shadow*.cpp
Shadow 已按 Core / Outline / Resources 拆分，降低单文件耦合与回归扩散。
src/d3d9/war3/render/war3_frame_graph.*
事件序列帧图计划，统一 BeforeUi/BeforePresent 事件分发顺序。

关键 Hook 点

war3_hook_address_book.*
所有 1.27a RVA 集中管理，消除多处硬编码。
d3d9_war3_hook.cpp
瘦身后的中枢文件：生命周期编排 + 域模块装配。
war3_hook_render.*
RenderDispatcher/WorldDispatch/Dispatch* 主链路拦截。
war3_hook_shadow.*
ListA/ListB/Projector/WriteEntry 阴影链路拦截与统计编排。
war3_shadow_filter_policy.*
阴影对象过滤策略（Ubersplat Key/FourCC 提取与黑名单判定）。
war3_hook_install_util.*
统一 MinHook 安装器，收敛 Create/Enable/错误日志格式。
war3_module_api.*
模块状态机与运行时统计（dispatch/handler/error）用于健康诊断。
Hook 系统基于 MinHook；分域文件保持“薄 Hook + 厚桥接”，入口层不承载域内策略细节。
