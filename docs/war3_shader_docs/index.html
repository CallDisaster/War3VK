入口与目标

War3Material 提供可热重载的 HLSL 管线，目标是把光照、描边等效果从 C++ 硬编码迁移到外部 Shader 资源。引擎只负责提供数据与状态，渲染表现完全由开发者掌控。

核心思想
寄存器即 Uniform。C++ 将世界状态写入寄存器，HLSL 负责输出风格。
兼容路径
当没有覆盖材质时，渲染路径回退到原生 fixed-function / 旧版 shader。
开放目标
让二开作者像 Iris 一样，把效果做成包、切换包、热改包。
提示：默认包已提供世界光照与几何描边示例，启用方式见 JSON 配置页。

框架与算法总览

此页整理“逻辑层 → 桥接层 → 渲染层 → ShaderPack”的完整路径，并给出当前采用的算法清单与组合评估。

分层结构

逻辑层
JASS / C API 写入渲染设置与句柄列表，触发事件链。
桥接层
SceneCollector + ExecBatch/TLS 解析 SceneNode → jHandle。
渲染层
War3Pipeline 负责 ShadowReceiver / SSAO / Outline / ShaderPack。
扩展层
ShaderPack JSON + HLSL/GLSL + ImGui 实时调参。

算法清单

CSM 级联阴影
级联分区 + 过渡带混合，支持 1~4 级联。
PCF / PCSS
PCF 支持 3x3/5x5/Poisson16/Poisson25，旋转可选屏幕/世界稳定。
NormalBias
深度重建法线 + 法线偏移，默认启用以抑制自遮挡条纹。
Alpha Shadow
支持 Hash Alpha / Mip / LOD Bias / 远级联阈值偏移，改善树叶阴影毛刺抖动。
AdaptiveBias
基于入射角的自适应偏移，进一步缓解对象自遮挡条纹。
时间线性阴影高度
用时间线性映射日夜高度，阴影长度变化更均匀。
线性滤波阴影采样
ShadowMap 线性采样，降低树影与墙面闪烁。
轮廓光
基于视角法线的边缘提亮，可用于夜战或英雄强调。
屏幕空间描边
双通道 Mask + 边缘检测，支持可见/遮挡开关。
几何描边
背面扩展 + 轮廓渲染（Silhouette / Fill）。
SSAO
随机采样半径 + 强度曲线 + 距离衰减。
Bloom / 曝光
亮度阈值 + 软膝 + 强度控制。
日夜与环境
日夜光照插值 + 环境光/曝光调整。

组合评估

  • 当前组合（CSM + PCF + NormalBias + 屏幕空间描边）在成本/质量间较平衡，适合主线默认。
  • PCSS 成本较高，推荐用于高端设备或战斗镜头短时启用。
  • 几何描边与屏幕描边互斥，避免重复绘制导致过亮或边缘噪点。
  • NormalBias 能明显缓解自遮挡条纹，但过大可能出现“peter-panning”。
  • AdaptiveBias 适合条纹明显的机型，但偏移过大仍可能出现轻微漂浮感。
  • 时间线性高度适合强调昼夜均匀变化；真实高度更接近物理轨迹。

已落地的性能优化

  • 时间平滑（PLL）：对 War3RenderState::GetGameTime() 的 100ms 台阶做“速度外推 + 误差回正”，把太阳时间从 10Hz 跳变变为逐帧连续，显著降低高机位阴影抖动/刺闪。
  • 后处理 Ping-Pong：BeforeUi 阶段仅一次性拷贝 SceneColor/SceneDepth，并通过 War3PipelineInput.srcColorView/depthCopyView 将输入在 Shadow/SSAO/AA 间串联，减少重复全屏 Copy 的固定带宽税。
  • ShadowCapture 冻结裁剪：冻结动态 VB/IB 时只 Copy 本次 draw 实际需要的字节范围，并重映射 draw 参数，避免“从 offset 到 buffer 末尾”整段冻结。
  • ShadowMap 级联剔除：为投射体记录保守包围球（center+radius），ShadowMap 每级联做裁剪空间包围球测试，减少多级联重放的无效 draw（兵海/超大地图收益更明显）。
  • ShadowMap 排序 + 状态去重：按 pipelineHash/纹理/VB/IB 排序，并缓存 pipeline/纹理/VB/IB 绑定状态，减少 Vulkan 绑定调用次数与 CPU 开销。
  • 非骨骼对象 GPU 端 MVP：将非混合物体 worldMatrix 追加写入矩阵 SSBO，在 VS 内计算 (pos * world) * lightVP；CPU 侧仅推 lightVP + matrixIndex。同时修复矩阵 SSBO 的 set/binding 与 DXVK bindless sampler heap 约定不一致导致的描边/遮罩不生效问题。

Shadow TAA（时域阴影滤波）

  • 目标：降低 Alpha-Test（树叶/栅栏等）阴影边缘的帧间闪烁。
  • 核心思路：把“当前帧阴影可见性”与“历史阴影可见性”按运动向量重投影对齐，再做指数移动平均（EMA）。
  • 鬼影抑制：可选 3x3 邻域夹紧（Neighborhood Clamping），将历史值限制在当前邻域的 min/max 范围内。
  • 限制：当前阶段仅生成“相机运动向量”（深度重建 worldPos + prevViewProj 重投影），不包含逐物体动画/位移/骨骼的运动向量。
  • 调试：ShadowDebugMode 新增 MotionVector/ShadowHistory 可视化。
// 1) ShadowVisibility（当前帧）
vis = PCF/PCSS(ShadowMap, depthReconstructWorldPos)
write ShadowCurrent(R8)

// 2) MotionVector（相机）
mv = currUv - prevUv      // 由 depth 重建 worldPos 后重投影
write MotionVector(RG16F)

// 3) Receiver（时域混合）
historyUv = uv - mv
history = sample(ShadowHistory, historyUv)
history = clamp(history, min/max(ShadowCurrent 3x3))
finalVis = mix(history, currVis, blendFactor)
store ShadowHistoryWrite(finalVis)
参考：UE4 “High Quality Temporal Supersampling”（Karis, 2014）、Frostbite TAA（Jimenez 等）、SMAA T2x（Jimenez）。

可优化方向

  • 引入 EVSM/VSM 或 caster 端 slope-scale bias，进一步稳定大角度阴影。
  • 为 CSM 增加分区稳定化（snap-to-texel），减少相机抖动。
  • 描边增加深度+法线边缘检测阈值，提升细节可控性。
  • 对 SSAO/PCSS 增加降分辨率与时域降噪，降低帧内开销。

模型管线（逆向中）

  • 已建立 set_model Hook 与路径重映射入口，用于记录模型加载与预留 FBX 注入点。
  • 当前策略为“FBX 预转换为 MDX + 路径替换”，后续可接入实时转换器。

渲染阶段

当前 War3Material 针对三个关键阶段提供覆盖入口：

World
世界渲染阶段。用于替换单位/地形的光照逻辑。
Outline
几何描边阶段。配合单位描边列表，重绘轮廓。
PostProcess
后处理阶段。用于全屏合成/色调映射。当前 composite/final 名称会映射到此阶段。

阶段选择由 shader_packs.json 中的 passes 指定。

SceneColor / SceneDepth

主屏渲染完成后的颜色与深度缓冲。可通过 Shader API 获取：

const auto* color = war3shader::GetRawColorBuffer();
const auto* depth = war3shader::GetRawDepthBuffer();
说明：War3Material 当前直接使用 D3D9 纹理槽（s0...），不直接访问 Vulkan Buffer。若需要读取 SceneColor/SceneDepth，请通过 Shader API 获取 vkImageView 并自行管理布局。

ShadowColor

Buffer

Shadow pass 提供两张颜色附件，用于输出阴影数据：shadowcolor0 与 shadowcolor1。

读取
任何 pass 都可以读取 shadowcolor 纹理，用于合成或调试。
写入
shadow / shadowcomp 阶段可写入 shadowcolor。可通过 RENDERTARGETS 选择目标。
格式
默认 RGBA8，可通过 Image Format 指令配置精度。
该条目为 Iris 风格示例标签，当前 War3MapReforge 内部实现仍在推进中，具体绑定以版本更新为准。

OutlineMask

Outline 相关缓冲包含可见/遮挡两张 mask，用于屏幕空间描边。

  • Mask 仅在启用屏幕空间描边时生成。
  • 若启用 Outline 材质覆盖（几何描边），该路径会被跳过。
调试提示：如需对所有对象强制启用描边，可设置 DXVK_WAR3_OUTLINE_ALL=1，或在脚本中调用 DXVK_SetOutlineAllObjectsEnabled(1)。

回退策略

稳定性优先：任何模块异常都会自动降级，避免影响原版渲染。

ShaderPack 回退
运行/编译失败会自动禁用当前 pack，并记录错误码，需手动 Reload 才会重新启用。
内置 Pass 回退
阴影/描边/SSAO 等内置 Pass 一旦抛出异常会被单独禁用，不影响其它 Pass。
原版回退
后处理失败会自动关闭 postFx.enabled，恢复原版输出。

回退链路

ShaderPack → 内置渲染效果 → 原版渲染
建议在二开模块中为关键 Pass 设置开关，以便在异常时快速降级。

SHADOW_RENDER_END 阴影渲染结束后 阴影后处理

Vulkan ShaderPack

Vulkan ShaderPack 通过 SPIR-V 文件驱动后处理与阴影接收器。当前支持 composite/final pass 以及 shadow_receiver 覆盖。 

{
  "name": "My Vulkan Pack",
  "enabled": true,
  "render_scale": 1.0,
  "shadow_receiver": "shadow_receiver.spv",
  "passes": [
    { "name": "composite", "shader": "composite.spv", "enabled": true },
    { "name": "final", "shader": "final.spv", "enabled": true }
  ]
}
pack.json 可省略：将 composite.spv / final.spv 放在目录下即可被自动识别。

模板目录：docs/war3_shader_docs/vulkan_pack_template（含 pack.json、GLSL 示例与 build.bat）。

纹理加载：SetTextureFromFile 支持常见图片格式（PNG/JPG/TGA/BMP/GIF/HDR/PNM），相对路径优先以 pack 目录解析，其次尝试原始路径或 MPQ。

示例模块：src/d3d9/war3/war3_user_example.cpp，设置环境变量 DXVK_WAR3_USER_EXAMPLE=1 自动加载示例 pack。

调试提示：ImGui 面板内可切换 Shadow Receiver 覆盖，用于排查自定义阴影接收器导致的崩溃。

#extension GL_EXT_samplerless_texture_functions : require

layout(set = 0, binding = 0) uniform sampler s_samplers[];

layout(set = 1, binding = 0, std140) uniform War3PackUBO {
  mat4 u_view;
  mat4 u_proj;
  mat4 u_invView;
  mat4 u_invProj;
  vec3 u_cameraPos;
  float u_gameTime;
  vec2 u_resolution;
  float u_frameTime;
  float u_totalTime;
};

layout(set = 1, binding = 1) uniform texture2D u_colorTex;
layout(set = 1, binding = 2) uniform texture2D u_depthTex;
layout(set = 1, binding = 3) uniform texture2D u_tex0;
layout(set = 1, binding = 4) uniform texture2D u_tex1;
layout(set = 1, binding = 5) uniform texture2D u_tex2;
layout(set = 1, binding = 6) uniform texture2D u_tex3;
layout(set = 1, binding = 7) uniform texture2D u_prevPass;

layout(push_constant) uniform War3PackPush {
  uint u_samplerColor;
  uint u_samplerDepth;
  uint u_samplerTex0;
  uint u_samplerTex1;
  uint u_samplerTex2;
  uint u_samplerTex3;
  uint u_samplerPrev;
  uint u_samplerPad;
  vec4 u_params0;
  vec4 u_params1;
  vec4 u_params2;
  vec4 u_params3;
};

vec4 sampleColor(vec2 uv) {
  return texture(sampler2D(u_colorTex, s_samplers[u_samplerColor]), uv);
}
当前 Vulkan ShaderPack 仅支持 SampleCount=1 的目标，不支持 MSAA 场景。
