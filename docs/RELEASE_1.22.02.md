# WarVK 1.22.02 候选范围（尚未发布）

本文件定义下一维护版的候选范围；只有完成下列门禁并记录最终 DLL 与源码身份后，才可将其改为正式发布说明。已发布的 v1.22.01 不变。

## 候选改动

- 地图 JASS Native 表重建时请求阴影会话切换，并在 Present 所有者安全点应用 Reset 与资源退休。限定 `ChangeLevel` A→B→A 已见 epoch 1→2→3、请求/应用 0→1→2 和旧会话收集 0→1→2；不把这条路径扩写成所有换图方式均已验证。
- 单位移动自动 Walk 重选开关和动画 Override 作者助手。限定 `Hamg` 隔离测试已见 JASS 请求接受、自动 Walk 抑制；关闭开关不会立即停止正在播放的动画。
- 持久阴影几何发布失败回滚、live/retired 账、帧取证当前尝试归因和截图退出同步 I/O 取消交接。
- Shader API 仍为 1.2.0，JASS wire 仍为 `warvk:v1`；不引入附加点世界坐标 API、64 位渲染产品、未完成 Water 或自动原版模型灯。

## 发布前门禁

1. 固定源码与 gitlink，排除 StormBreaker 工作树未提交内容；独立全新正式配置构建，开发采集与诊断选项关闭、蒙皮正确性合同按正式配置开启。核对 PE32/i386、版本、精确 DLL no-work 与 SHA。
2. 断言开启的 Win32 CPU 测试、全量静态、JASS/YDWE 作者目录、实际发布包成员/CRC/SHA 全通过；无旧测试结果跨源码身份复用。
3. 隔离 2560×1440、零全局输入验证冷启动和同进程换图，包含菜单返回/再进图、D3D9 Reset、高压与恢复；核 epoch、请求/应用、退役/收集、合法 caster、receiver、GPU 事件和资源账户，记录未覆盖项。
4. 单位动画覆盖关闭/恢复、至少另一单位类型、死亡/句柄复用与地图切换；播放器视觉与实际 DLL/地图身份绑定。不能只凭全局 Hook 计数认证同对象恢复。
5. 审核 changelog/README 的实际证据强度，不承诺 FPS 收益或全面解决历史间歇性阴影问题。发布事务只允许新的 v1.22.02 标签和白名单附件，不移动旧标签、不覆盖玩家现场 DLL。
